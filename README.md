# 🎯 AyuGram Focus Plugin (Spotlight Focus)

> Превращает Telegram из отвлекающей ленты новостей в инструмент с фокусом на намерениях (Intent-based / Command Palette).

Вместо шумной ленты с бесконечными каналами, чатами и красными кружками непрочитанных сообщений, плагин оставляет чистый экран со строкой поиска — в стиле **macOS Spotlight, Alfred или Raycast**.

---

## ⚡ Как это работает

1. **Чистый экран:** При входе в Telegram список чатов скрыт. Никаких картинок, кликбейтов и чатов не загружается.
2. **Карточка Focus Mode:** В центре экрана отображается минималистичный статус и кнопка быстрого поиска.
3. **Поиск без шума:** Вы вводите имя собеседника или бота (например, бот для скачивания видео) — отображаются только точные результаты поиска.
4. **Удобные настройки:** Режим можно легко настроить или временно отключить в меню плагинов.

---

## 📦 Установка на телефон (Android)

Для установки не нужно пересобирать APK:

1. Скачайте или отправьте готовый файл [`ayugram_focus.plugin`](./ayugram_focus.plugin) себе в Telegram (например, в **«Избранное» / Saved Messages**).
2. Нажмите на прикрепленный файл `.plugin` прямо в чате на телефоне.
3. В появившемся окне нажмите **«Установить плагин» (Install Plugin)**.
4. Готово! Плагин активируется сразу же.

Управление параметрами доступно в:
`Настройки` → `Настройки AyuGram / exteraGram` → `Плагины` → `AyuGram Focus`.
